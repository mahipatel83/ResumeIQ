# 🎯 ResumeIQ

> **An AI-powered Resume Analysis and Job Recommendation Platform built with Django, React, MongoDB, NLP, and Machine Learning.**

ResumeIQ is a full-stack recruitment platform designed to help **candidates analyze and improve their resumes** while enabling **recruiters to create job postings and manage applications**.

The platform uses **Natural Language Processing (NLP), Machine Learning, resume parsing, ATS-oriented analysis, and skill matching** to provide intelligent resume insights and relevant job recommendations.

---

# 📌 Project Overview

ResumeIQ is designed to simplify the recruitment process for both candidates and recruiters.

Candidates can upload their resumes, analyze their skills, receive ATS-oriented insights, identify missing skills, get improvement suggestions, and discover relevant job opportunities.

Recruiters can create job postings, specify required skills and experience, view candidate applications, and manage recruitment activities through a dedicated dashboard.

The platform combines **AI/NLP capabilities with a modern React frontend, Django backend, and MongoDB database** to create an intelligent recruitment ecosystem.
